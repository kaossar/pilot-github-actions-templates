# pilot-github-actions-templates

> **PILOT SaaS - pilot-github-actions-templates**

Dépôt centralisé des workflows CI/CD GitHub Actions pour PILOT SaaS. Contient les pipelines standards pour le déploiement Frontend, Backend et Terraform (Infrastructure as Code).

## 🏗️ Architecture et Standards
Ce projet respecte la **Clean Architecture** et les principes **SOLID** exigés par PILOT SaaS :
- **Maintenabilité** : Code lisible, structuré et documenté en français.
- **Sécurité** : Isolation stricte (RLS) et principes de moindre privilège.
- **Évolutivité** : Conception modulaire pensée pour le long terme (10+ ans).
